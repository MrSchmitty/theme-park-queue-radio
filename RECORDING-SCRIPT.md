# Park Radio — recording script

Every line works before any track, so one recording fits anywhere in the rotation.
`make-voices.py` generates these automatically; this document is for doing it by
hand, or for checking what a clip is meant to say.

```
your-repo/
  park-radio.html
  voices/
    manifest.json
    mansion/
      demo.mp3   01.mp3  02.mp3  03.mp3  04.mp3
    ...
```

`demo.mp3` plays when you tap a host chip to audition it. The numbered files are
the between-track breaks, chosen at random.
